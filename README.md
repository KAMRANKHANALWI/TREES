## Core Concepts

### 1. Binary Tree

A hierarchical data structure in which each node can have at most two children:

- Left Child
- Right Child

### 2. Tree Traversals

```text
DFS:
    Inorder
    Preorder
    Postorder

BFS:
    Level Order
```

### 3. Recursion

Trees naturally support recursive problem-solving.

```text
Solve left subtree
        ↓
Solve right subtree
        ↓
Combine results
```

### 4. Binary Tree Properties

- Height / Maximum Depth
- Balanced Binary Tree
- Diameter
- Maximum Path Sum
- Symmetry

### 5. Tree Views and Paths

- Top / Bottom View
- Left / Right View
- Vertical Traversal
- Boundary Traversal
- Root-to-Leaf Paths
- Lowest Common Ancestor

### 6. Tree Construction

Reconstruct binary trees using traversal sequences.

### 7. Morris Traversal

Traverse a binary tree using O(1) auxiliary space.

## Learning Goals

- Understand recursive and iterative tree traversals.
- Develop strong recursion and DFS intuition.
- Master BFS using queues.
- Understand tree height, diameter and path-based problems.
- Recognize tree-view and coordinate-based patterns.
- Learn binary tree construction.
- Understand Morris traversal.
